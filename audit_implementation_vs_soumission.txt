1. C1 — GIK -> IceChunk Conversion
   Statut : FAIT
   Fichiers : conversion/virtualizer.py, icechunk_writer.py, gik_loader.py, gap_filler.py
   Detail  : GIK Parquet -> VirtualiZarr -> IceChunk Zarr v3 virtual store.
              Zero duplication. Single zarr.open(). 150 246 Parquet files supportes.
              Gap-filling pour la periode Mai 2023 - Mars 2024.

2. Innovation 1 — IceChunk Time-Travel Audit Trail
   Statut : FAIT
   Fichiers : conversion/icechunk_writer.py
   Detail  : commit_day() avec tagging par date, checkout_as_of(date) pour
              requetes retrospectives, list_snapshots(), readonly_session(),
              compact(keep_days=30). Chaque batch GIK = un commit IceChunk.

3. C1 Benchmark
   Statut : FAIT
   Fichiers : conversion/benchmark.py, scripts/tools.py (commande benchmark)
   Detail  : Mesure storage (GB), time-to-first-byte (s), full-scan (s),
              egress cost (USD). Comparaison GIK+IceChunk vs dynamical.org.

4. C2 — Exceedance Analysis
   Statut : FAIT
   Fichiers : exceedance/accumulations.py, exceedance.py, writer.py, icechunk_output.py
   Detail  : Rolling accumulations (7 fenetres : 3h, 6h, 12h, 24h, 48h, 72h, 7j).
              Exceedance empirique : fraction membres > seuil.
              6 return periods (2, 5, 10, 20, 40, 100 ans).
              Sortie multi-dim Zarr v3 : date x lat x lon x window x return_period.
              Profils : flash_flood, medium_range, full.

5. Innovation 2 — Adaptive GEV Thresholds (Saison + IOD/ENSO)
   Statut : FAIT
   Fichiers : exceedance/thresholds.py
   Detail  : AdaptiveGEVThresholds avec stratification par :
              - Saison (MAM, OND, JJAS, DJF)
              - Phase ENSO (El Nino / Neutre / La Nina via N3.4)
              - Phase IOD (Positif / Neutre / Negatif via DMI)
              ClimateMode dataclass combine les 3 dimensions.
              GEV fitting par cellule de grille. Reduit les fausses alarmes.

6. Innovation 3 — Manifest-Aware Loader + Byte-Range Coalescence
   Statut : FAIT
   Fichiers : exceedance/manifest_store.py, shared/byte_range.py
   Detail  : Lecture VirtualChunkRefs depuis IceChunk (pas HuggingFace).
              Coalescence byte-ranges adjacents (~714 ranges -> ~60 requetes S3).
              Fetch parallele S3 via ThreadPoolExecutor.
              Decode GRIB2 via eccodes avec bbox subsetting immediat.
              Dataset xr.Dataset concret en memoire (member, step, lat, lon).
              Configurable via component2.manifest_aware.enabled.

7. C3 — CRMA-Live Risk Engine
   Statut : FAIT
   Fichiers : risk/crma_model.py, risk_engine.py, aggregator.py, gpm_loader.py
   Detail  : Bayesian Network pgmpy avec 9 noeuds :
              Forecast_Hazard, Obs_Antecedent, Temporal_Persist, Spatial_Coverage,
              Data_Confidence, API_State, Soil_Memory, Compound_Risk, Risk_State.
              4 niveaux traffic-light : Green (0), Yellow (1), Orange (2), Red (3).
              ~300 unites admin-1 (11 pays Afrique de l'Est).

8. Innovation 5 — Dynamic BN avec API Persistence
   Statut : FAIT
   Fichiers : risk/dynamic_bn.py
   Detail  : DynamicBayesianNetwork avec noeud API :
              API(t) = observed(t) + decay x API(t-1).
              Soil_Memory : suivi des jours consecutifs de saturation.
              Matrice de transition API 3x3 configurable.
              Capture le risque compose multi-jours (saturation des sols).

9. Innovation 6 — EM-DAT CPT Refinement
   Statut : FAIT
   Fichiers : risk/cpt_refinement.py
   Detail  : MaximumLikelihoodEstimator sur evenements historiques EM-DAT.
              Echantillons positifs : jours d'inondation EM-DAT -> Risk_State=Red.
              Echantillons negatifs : jours aleatoires sans evenement -> Risk_State<=Yellow.
              Laplace smoothing avec alpha configurable.
              Raffinement CPT des noeuds feuilles uniquement.
