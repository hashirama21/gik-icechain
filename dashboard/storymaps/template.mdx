<Block>
  <Prose>
    ## Flood Risk Monitoring for East Africa

    The **GIK-IceChain** pipeline provides daily flood risk assessments
    for all admin-1 units in East Africa using a zero-cost cloud-native
    architecture built on ECMWF open data, IceChunk virtual stores, and
    the ICPAC CRMA Bayesian Network.

    Risk levels are computed by combining:

    - **Forecast hazard**: ensemble exceedance probabilities from 51 IFS members
    - **Observed antecedent**: GPM IMERG daily precipitation
    - **Soil memory**: Antecedent Precipitation Index (API) with exponential decay
    - **Spatial coverage**: fraction of grid cells with active signal
    - **Temporal persistence**: consecutive days with rainfall signal
  </Prose>
</Block>

<Block>
  <Prose>
    ## Exceedance Probabilities

    The exceedance layer shows the fraction of ensemble members where the
    worst-case 24-hour accumulated precipitation exceeds the CMORPH-derived
    5-year return period threshold. Values above 0.4 (40% of members)
    correspond to a **High** forecast hazard state in the CRMA model.
  </Prose>
