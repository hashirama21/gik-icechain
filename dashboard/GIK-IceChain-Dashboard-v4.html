Dependency Order — 5-Step Reload Logic

① Date selected — IFS ENS forecast cycle (00z / 06z / 12z / 18z)
② Country + Admin-1 region — 11 East African countries, 177 admin-1
③ Max severity per accumulation window — 7 windows (3h, 6h, 12h, 24h, 48h, 72h, 7d)
④ GEV results for selected window — 100y → 2y hierarchical evaluation
⑤ Ensemble chart for selected GEV — 51 members, binary comparison

GEV Thresholds — Minimum Operational Probabilities

Evaluation order: 100y first → 2y last. First condition met = window severity score. Higher return periods require lower probability thresholds (asymmetric cost of missed catastrophic event).

Return PeriodMin P%Min members / 51Severity

20 years≥ 20%≥ 11High

5 years≥ 40%≥ 21Moderate

Risk Metrics (Core)

Exceedance Probability
% of ensemble members (out of 51) exceeding a GEV return period threshold for a given accumulation window. Computed as: count(members exceeding threshold) / 51.
Source: IFS ENS · ECMWF
Return Period Triggered
Highest GEV return period threshold that meets its minimum probability requirement. Evaluated 100y → 2y; first condition met = severity score for the window.
Source: CMORPH (GEV calibration)
Max Ensemble Signal
Maximum exceedance probability across all 7 accumulation windows for a given day and district. Single number summarising the most dangerous time horizon.
Source: IFS ENS · Component 2
Admin-1 Risk Level
Aggregated risk score per Admin-1 region (Low / Medium / High / Critical) produced by the CRMA Bayesian network (Component 3), integrating exceedance forecast, GPM IMERG observations, and soil saturation.
Source: Component 3 · Bayesian CRMA

Forecast Performance Metrics

Hit Rate (POD — Probability of Detection)
Days where the forecast signalled a risk (exceedance > threshold) AND an EM-DAT flood event was confirmed within ±2 days. POD = TP / (TP + FN).
Source: IFS ENS vs EM-DAT
False Alarm Ratio (FAR)
Proportion of risk alerts not followed by a confirmed EM-DAT event. FAR = FP / (TP + FP). High FAR erodes institutional trust in the tool.
Source: IFS ENS vs EM-DAT
Missed Events
EM-DAT flood events not detected by the ensemble (no signal above threshold within ±3 days of the event). Critical for evaluating operational reliability.
Source: EM-DAT
Lead Time (avg hours)
Average number of hours before a confirmed EM-DAT event that the forecast first signalled a risk above the minimum probability threshold. Higher lead time = more time for preventive action.
Source: IFS ENS
